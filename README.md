# DEBK: Digital Double Entry Bookkeeping

This project is an experimental initiative to learn how best to utilise Artificial Intelligence (AI), specifically Large Language Models (LLMs), to perform end-to-end software development—from initial requirements through to design and implementation.

The primary objective is to determine the optimal approach for employing AI to:

- **Analyse requirements:** Research project domain descriptions written in natural language by applying techniques such as semantic data modelling and use-case analysis.
- **Produce design specifications:** Create data models that apply Domain-Driven Design (DDD) methodology to align the code with the business domain, alongside design thinking to derive User Experience (UX) models.
- **Implement:** Generate code in Go, SQL (for SQLite), and JavaScript/ReactJS.

As an experiment, this project is developed on an iterative basis to continuously refine the methodologies used for AI-driven software engineering. Consequently, the project is subject to changes without notification.

## Scope

1. This project used free tier version of Gemini as the baseline LLM.

2. The bookkeeping domain is not exhaustive and limited in scope purely for experimentation.

## Disclaimer

This project is experimental in nature. The resulting code should not be expected to be production-ready. Any intention to use this software for mission-critical systems is entirely at your own risk.
